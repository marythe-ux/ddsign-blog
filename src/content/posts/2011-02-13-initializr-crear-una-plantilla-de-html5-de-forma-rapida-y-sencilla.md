[Initializr](http://initializr.com/) es una herramienta de [HTML5 Boilerplate](http://html5boilerplate.com/), un conjunto de [plantillas HTML, CSS y JS](http://initializr.com/) para el inicio de sitios web, de un modo rápido, robusto y profesional, apto ya para [HTML5](http://www.w3.org/html/logo/).  
  
Con **Initializr** podrás generar tu sitio web totalmente personalizable basado en las *plantillas Boilerplate*, escogiendo los elementos que necesitas y desde Initializr crear los ficheros que te servirán de base para construir tu sitio.

Entre las características de *HTML5 Boilerplate* destacamos:  

  
-   Multinavegador (también IE6)
  
-   Preparado para HTML5
  
-   Optimizaciones para la visualización en navegadores para móviles
  
-   Clases específicas para IE, que facilitan un mayor control multinavegador
  
-   Perfiles Javascript en función del navegador
  
-   Una hoja de estilos de impresión óptima
  
-   IE6 pngfix
