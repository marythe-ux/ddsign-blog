El plugin [WP Maintenance Mode](http://wordpress.org/extend/plugins/wp-maintenance-mode/) para Wordpress nos permite que mientras tenemos nuestro blog wordpress en construcción que el usuario pueda ver otra página diferente (que nosotros podemos personalizar totalmente) y nosotros mientras tanto vamos construyendo el blog por debajo de modo no visible para el usuario.

[![enConstruccion](/wp-content/uploads/2011/03/enConstruccion.jpg)](/wp-content/uploads/2011/03/enConstruccion.jpg)  
  
*WP Mantenaince Mode* añade a tu blog una **landing page** que deja ver que tenemos el sitio en construcción. Como ya adelantaba, mientras el administrador tiene total acceso al back-end y al front-end y puede ir preparando la nueva apariencia del sitio.

La *landing page* se puede personalizar con unas opciones que ya trae el plugin o podemos cambiar la apariencia completamente.  
Maqueta la página a tu gusto, después añade la hoja de estilos CSS a las opciones del plugin y elígela, más tarde sube a tu sitio todas las imágenes y archivos que te hagan falta para la landing page. El archivo php que has de modificar es el llamado **site.php.**
