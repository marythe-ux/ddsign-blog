[WP Google Fonts](http://wordpress.org/extend/plugins/wp-google-fonts/) es un plugin de Wordpress que nos facilita mucho a la hora de embeber en nuestra web fuentes de [Google Font](http://www.google.com/webfonts#HomePlace:home).

El plugin nos facilita un desplegable en el cual podemos elegir las fuentes deseadas, con la ventaja de que este listado de fuentes se actualizará a medida que vayan surgiendo nuevas entradas en Google Directory.

Desde el fichero se pueden asignar estilos y personalizar la CSS de las fuentes de las class y los id de nuestro tema de forma muy sencilla y rápida.
