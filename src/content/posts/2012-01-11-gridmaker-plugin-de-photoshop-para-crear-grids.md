Recientemente en [Smashing Magazine](http://www.smashingmagazine.com/2012/01/03/guideguide-free-plugin-for-dealing-with-grids-in-photoshop/ "GuideGuide") recomendaban un plugin para Photoshop para crear *grids* (retículas), GuideGuide. Este plugin es para CS4 y CS5, así que por ahora no tengo la suerte de poder probarlo.

Un plugin similar para photoshops inferiores a CS4 es [GridMaker](http://andrewingram.net/articles/introducing_gridmaker/ "GridMaker"). Lo estoy empezando a usar y me va bien, aunque no tenga tanta flexibilidad como promete GuideGuide.
