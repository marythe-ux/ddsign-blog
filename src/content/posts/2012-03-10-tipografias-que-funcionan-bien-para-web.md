El uso de **fuentes seguras** para web se ve bastante limitado si no optamos por embeber las fuentes mediante @font-face o sirviéndonos de Google Fonts. Aún así no todas las tipografías a las cuales de este modo podemos tener acceso son adecuadas para nuestros diseños web. Por ello que listados como estos siguientes nos vienen muy bien para saber qué fuentes resultan mejor:

-   [20 Fuentes gratis sans-serif para utilizar con font-face](http://line25.com/articles/20-free-sans-serif-fonts-licensed-for-font-face "20 Free Sans Serif Fonts licensed for font-face")
-   [Una selección de las mejores tipografías del directorio de Google web fonts.](http://hellohappy.org/beautiful-web-type/ "Beautyful web type")
