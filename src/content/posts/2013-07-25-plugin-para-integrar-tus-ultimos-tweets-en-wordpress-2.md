Hace un par de años escribí en **Ddsign** el post titulado [Integrar tus últimos tweets en tu blog sin utilizar un plugin](/2011/12/28/ultimos-tweets-sin-plugin/ "Integrar tus últimos tweets en tu blog sin utilizar un plugin") en el que os contaba un método para incrustar las últimas entradas de Twitter en nuestro web o blog sin necesidad de utilizar ningún plugin.

El método descrito allí queda obsoleto porque se estaban realizando llamadas a una API de Twitter que ahora ya no existe. También ahora el método de autenticación de nuestra cuenta es más complejo.

Así que yo ahora voy a utilizar el siguiente plugin: [Really Simple Twitter Feed Widget](http://wordpress.org/plugins/really-simple-twitter-feed-widget/ "Really Simple Twitter Feed Widget"), actualizado para la versión 3.5.2  
Este plugin dispone los últimos tweets de tu cuenta de Twitter como widget en la sidebar. Este plugin ya conecta con la API 1.1 de Twitter.

Después de instalar el plugin, deberás ir a Apariencia > Widgets y allí arrastrar la pastilla del plugin a la sidebar deseada. En el Widget ya tendremos un enlace a la configuración de la API para obtener las claves que vamos a necesitar para la configuración. La personalización del widget es buena, podemos establecer cuántos tweets queremos mostrar, establecer un título para este bloque, si queremos mostrar nuestro avatar, si deseamos mostrar los RT's, nos permite dejar un link a nuestra cuenta...etc, la verdad es que deja personalizar casi todo. Lo he encontrado muy completo.

Si conocéis otro plugin de este estilo que sea interesante, no dudéis en comentarlo.
