Dos de los sistemas más famosos para embeber fuentes tipográficas en la web son [Google Fonts](http://www.google.com/fonts/ "Google Fonts") y, ya más reciente, [Adobe Edge Fonts](https://edgewebfonts.adobe.com/index "Adobe Edge Fonts").

Podemos necesitar combinar dos o más tipografías para nuestros diseños web y resulta difícil decidirse por el gran número de opciones que existen. Pero elegir tipografías que queden bien juntas no es tarea fácil.

## Probar las fuentes tipográficas

En Adobe Edge Fonts nos dan cierta ayuda a la hora de elegir las tipografías para titulares o para párrafos. Como véis en la imagen he marcado *headings* (titulares).

[![headlines](/wp-content/uploads/2013/08/headlines.jpg)](https://edgewebfonts.adobe.com/index)

Las tipografías de Google Fonts se pueden probar de modo mucho más visual en [Best Web Fonts](http://www.bestwebfonts.com/ "Best Web Fonts") y además también se pueden probar estilos CSS3. Seleccionaríamos una fuente del listado de la derecha y en la izquierda vamos viendo cómo queda:

[![bestwebfonts](/wp-content/uploads/2013/08/bestweb.jpg)](http://www.bestwebfonts.com/)

## Probar varias combinaciones de fuentes tipográficas

Para probar de un modo cómodo varias combinaciones de fuentes, utilizar una para titulares y otra para otros elementos, podemos servirnos de [Font-combinator](http://font-combinator.com/ "font-combinator"):

[![font-combinator](/wp-content/uploads/2013/08/font_combinator.gif)](http://font-combinator.com/)

Font-combinator nos facilita el hacer pruebas a la hora de combinar varias fuentes del repositorio de Google Fonts. Podemos probar el tamaño, el interlineado, el font-weight de la fuente y el color.

## Probar combinaciones de fuentes desde la web de Google Fonts

En la misma web de [Google Fonts](http://www.google.com/fonts "Google Fonts") también nos facilitan la tarea de ver qué tipografías podemos combinar, aunque yo opino que este servicio se encuentra un poco oculto.

Entramos en la web y a la derecha de la fuente que nos interesa vemos un cuadrito gris que si pasamos el ratón por encima dice "pop-up" y pulsamos ese botón.

[![pop up](/wp-content/uploads/2013/08/pop-up.gif)](/wp-content/uploads/2013/08/pop-up.gif)

Entonces llegamos a esta pantalla:

[![character set](/wp-content/uploads/2013/08/character_set.gif)](/wp-content/uploads/2013/08/character_set.gif)

Y donde nos interesa pinchar es en la última opción,**Pairings**, donde nos van a hacer sugerencias de otras fuentes que pueden quedar bien con la tipografía que nosotros hemos seleccionado:

[![pairing](/wp-content/uploads/2013/08/pairing.gif)](/wp-content/uploads/2013/08/pairing.gif)

## Recopilaciones visuales de combinaciones de fuentes

En la web también encontramos ejemplos de combinaciones de fuentes web en blogs de diseño. Sus autores se han preocupado de hacer muestras muy armónicas de pares de fuentes, por ejemplo estos (muchos más ejemplos en su blog):

[Beautiful Web Type](http://hellohappy.org/beautiful-web-type/ "Beautiful web type") es un *showcase* de las mejores combinaciones de las tipografías del directorio de fuentes web, Google web fonts (en hellohappy.org). Un modo muy visual de ver estas tipografías en acción.  
[![http://hellohappy.org](/wp-content/uploads/2013/08/hellohappy.gif)](http://hellohappy.org/beautiful-web-type/)

Otra recopilación de combinación de tipografías de Google web fonts es la de [Bueltge.de](http://bueltge.de/free-web-font-combinations/ "bueltge.de"). Este proyecto está en [GitHub](https://github.com/bueltge/Free-Web-Font-Combinations "Free Web Font Combinations").  
[![http://bueltge.de](/wp-content/uploads/2013/08/bueltge.jpg)](http://bueltge.de/free-web-font-combinations/)

En [Awwwards](http://www.awwwards.com/best-20-webfonts-from-google-web-fonts-and-font-face-embedding.html) también hay muy buenos ejemplos.
