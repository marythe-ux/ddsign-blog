Esta es una pequeña recopilación de tutoriales y demostraciones de menús off-canvas.

## [Foundation Off-canvas](http://foundation.zurb.com/docs/components/offcanvas.html "Foundation")

El framework Foundation viene preparado con componentes para crear menús [Off-canvas](http://foundation.zurb.com/docs/components/offcanvas.html "off-canvas") de una forma sencilla.

## [Pushy](http://christopheryee.ca/pushy/ "Pushy off-canvas")

[Pushy](http://christopheryee.ca/pushy/ "Pushy off-canvas") es un menú off-canvas responsive creado con trasiciones y transformaciones CSS, desarrollado por [Chistopher Yee](http://christopheryee.ca/ "Chistopher Yee"). Está preparado para funcionar en navegadores antiguos como IE7

## Menú Off-canvas con CSS:target, [CSS Tricks](http://css-tricks.com/off-canvas-menu-with-css-target/ "Menu with CSS target")

[Menú Off-canvas con CSS:target](http://css-tricks.com/off-canvas-menu-with-css-target/ "Menu with CSS target") está creado sólo con CSS y no necesita Javascript pero es soportado por navegadores modernos (por ejemplo superiores a IE9) debido al uso de etiquetas CSS3.

## Varias implementaciones del [menú off-canvas](http://coding.smashingmagazine.com/2013/01/15/off-canvas-navigation-for-responsive-website/ "menú off canvas")

En Smashing Magazine dedican un artículo a explicar diferentes modos de implementar un[menú off-canvas](http://coding.smashingmagazine.com/2013/01/15/off-canvas-navigation-for-responsive-website/ "menú off canvas") dando ejemplos de menús realizados siguiendo los principios del [progressive enhancement](http://en.wikipedia.org/wiki/Progressive_enhancement "progressive enhacement") y utilizando transiciones CSS.

## [Repertorio de efectos para menús off-canvas](http://tympanus.net/Development/SidebarTransitions/ "sidebar transitions")

En [Tympanus.net](http://tympanus.net/Development/SidebarTransitions/ "sidebar transitions") podemos ver un buen reportorio de efectos para menús off-canvas
