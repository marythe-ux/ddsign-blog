Esta es mi selección de libros y ebooks sobre diseño web. Algunos son gratuitos y se pueden leer online, otros incluso permiten la descarga, otros son de pago y se pueden conseguir en formato físico y/o digital.

## Diseño Web

### Designing for the Web

![designing](/wp-content/uploads/2012/11/designing.jpg) [Designing for the Web](http://say2waw.blogspot.com.es/2012/05/designing-for-web-mark-boulton-2009.html "Designing for the Web") de Mark Boulton. Se describe el tipo de trabajo, el briefing, el proceso de diseño, hablará sobre los bocestos, las herramientas, el color, las tipografías, el layout … El libro comienza así:

> “El diseño web es diferente al diseño para cualquier otro medio. La amplitud de los conocimientos exigidos al diseñador a veces es desalentador. La experiencia requerida, aparentemente inalcanzable. Sin embargo, el medio atrae a diseñadores de todas las esferas de la práctica del diseño: desde la ingeniería y la arquitectura, el producto y el diseño gráfico \[...\]“

## Responsive Design

### Responsive Web Design y Mobile First

[![books](/wp-content/uploads/2012/05/books.jpg)](http://www.abookapart.com/products/responsive-web-design) [“Responsive Web Design”](http://www.abookapart.com/products/responsive-web-design "RWD") de Ethan Marcotte y [“Mobile First”](http://www.abookapart.com/products/mobile-first "Mobile First") de Luke Wroblewski. Son de los primeros ebooks que se publicaron sobre el tema del Responsive Design y diseños web para dispositivos móviles, pueden servir como punto de partida. Tratan el tema de forma clara y con ejemplos útiles de código HTML+CSS. Son libros muy prácticos de [A Book Apart](http://www.abookapart.com/ "A book apart"), donde encontraréis más libros técnicos en formato papel y también en PDF.

  

### Wordpress meet responsive design

En el blog [Code Poet](http://build.codepoet.com/2012/05/11/wordpress-meet-responsive-design/ "CodePoet") ofrecen la descarga de un libro digital (PDF, EPUB, KINDLE) titulado [“WordPress Meet Responsive Design”](http://build.codepoet.com/2012/05/11/wordpress-meet-responsive-design/ "Wordpress meet responsive design") acerca de cómo WordPress puede ser Responsive. Este libro recoge una serie de entrevistas a los pioneros del Responsive ( Ethan Marcotte, Chris Coyier, Ian Stewart, Sara Cannon… ) y enlaces a tutoriales y a ejemplos muy interesantes, recalcando siempre la idea de que WordPress no está reñido con un layout RWD.

  

### CSS Animations

[“CSS Animations”](http://valhead.com/book/ "CSS Animations"), una guía sobre las animaciones y transiciones CSS escrito por Val Head. Es un libro dedicado a diseñadores y desarrolladores web, los cuales quieren conocer las novedades de las animaciones CSS, quienes quieren comenzar a utilizarlas y a experimentar con ellas. [![css animaciones](/wp-content/uploads/2014/04/CSSAnimations.jpg)](http://valhead.com/book/)

  

### The Mobile Book

[The Mobile Book](https://shop.smashingmagazine.com/the-mobile-book-digital-edition.html "The Mobile Book") de Smashing Magazine, disponible en formato físico y digital. Es un libro muy completo sobre el tema de los dispositivos móviles. Muestra las peculiaridades del tema, desde aspectos relacionados con la estrategia como prototipado, diseño y codificacion.

## HTML para los más pequeños

### Web Design for Babies

[![html-infantil](/wp-content/uploads/2012/03/html-infantil.jpg)](http://www.thinkgeek.com/product/eacc/?cpg=cj&ref=&CJURL=&CJID=2617611#tabs) [Web Design for Babies, Volume 1](http://www.thinkgeek.com/product/eacc/?cpg=cj&ref=&CJURL=&CJID=2617611#tabs "html para bebés") es una chulada de libro para que los más pequeños conozcan el lenguaje HTML. Presenta los principales conceptos del diseño web a los bebés. El autor del libro es el diseñador web John C. Vanden-Heuvel Sr.
