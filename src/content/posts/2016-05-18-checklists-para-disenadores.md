A la hora de enfrentarse con un proyecto nuevo de diseño web hay muchos puntos que hay que tener en cuenta. Para no olvidarnos de ningún tema, es recomendable seguir una lista de puntos que debemos cumplir. Con el tiempo crearemos nuestra propia lista y la cubriremos de forma rutinaria pero puede sernos útil ver otras listas elaboradas por otros diseñadores y observar qué puntos suelen tener ellos en cuenta. Por ello he reunido aquí esta selección de *checklists* para diseñadores.

-   [A Product Design Process Checklist](https://www.8ballr.com/), una lista para revisar todo el proceso de diseño.

[![01_design_checklist](/wp-content/uploads/2016/05/01_design_checklist.png)](https://www.8ballr.com/)

-   [A Team Activity to Start a Design System](https://medium.com/eightshapes-llc/picking-parts-products-people-a06721e81742#.87m8q6s08), 'check list' para llevar a cabo el trabajo en equipo en Diseño.
-   [The Web Typography Checklist](https://studio.uxpin.com/ebooks/web-design-typography-checklist/), guía en PDF para revisar todos los aspectos de una web referentes a tipografía.

[![02_design_checklist](/wp-content/uploads/2016/05/02_design_checklist.jpg)](https://studio.uxpin.com/ebooks/web-design-typography-checklist/)

-   [The 23-Point UX Checklist](https://studio.uxpin.com/ebooks/ux-checklist/), 23 puntos para verificar la experiencia de usuario de un proyecto web.
-   [Webdesigner checklist](http://webdesignerschecklist.com/), la lista básica de revisión del diseñador web.
-   [Design checklist: what clients should provide their designers](http://www.traceygrady.com/graphic-design/design-checklist-what-clients-should-provide-their-designer), con esta lista podrás comprobar si has recibido todos los entregables y requisitos que necesitas de tu cliente antes de empezar un proyecto.
-   [The essential usability checklist for web app](http://blog.invisionapp.com/usability-checklist-for-web-apps/), lista para revisar la usabilidad de las aplicaciones web.

[![03_design_checklist](/wp-content/uploads/2016/05/03_design_checklist.jpg)](http://adrien-heury.net/designers-checklists/)

-   [Varias 'checklist' y consejos](http://adrien-heury.net/designers-checklists/) por parte de Adrien Heury, diseñador UI/UX francés y su hermana Noe, diseñadora de interacción. Recogen consejos de todo tipo como qué puntos seguir antes de comenzar un nuevo proyecto, lo que se debe tener en mente mientras diseñamos, los principios del buen diseño... y además tienen un cuidado diseño que facilita mucho la lectura.
-   11 pasos para el logo perfecto, guía creada por el diseñador [Borja Acosta de Vizcaíno](http://www.badvstudio.com/).
