## Bootstrap, un sistema de 12 columnas para construir webs responsive

**Bootstrap** es un framework o conjunto de herramientas de código abierto para diseño de sitios y aplicaciones web. Contiene plantillas de diseño con tipografía, formularios, botones, cuadros, menús de navegación y otros elementos de diseño basado en HTML y CSS, así como, extensiones de JavaScript opcionales adicionales. ![boostrap](/wp-content/uploads/2017/07/bootsrap_image-2.png) **Bootstrap** fue desarrollado por **Mark Otto** y **Jacbod Thornton** de Twitter, como un marco de trabajo (framework) para fomentar la consistencia entre las herramientas internas. Desde su versión 2.0 soporta diseño responsive (se ajusta dinámicamente a las características del dispositivo usado) y desde entonces se ha generalizado para la maquetación ágil de proyectos responsive, ya que simplifica el uso del CSS cross-browser y las [media-queries](/2012/04/28/sintaxis-y-diferentes-modos-de-llamar-media-queries/) para crear los diferentes breakpoints. Bootstrap no es la única opción para crear un sitio responsive ni tampoco la panacea; es una opción como otra cualquiera, pero es cierto que hoy en día es muy utilizado e incluso se demanda como punto de partida. Actualmente Bootstrap viene con un CSS preparado con [pre-procesadores Less y Sass](/2013/03/04/preprocesadores-css/).

Bootstrap utiliza un modelo de rejilla (o retícula o *grid*) basado en dos tipos de contenedores (uno con un tamaño fijo por cada grupo de dispositivos y otro que se basa en porcentajes) y un sistema de 12 columnas. En la misma web de [Bootstrap oficial](http://getbootstrap.com/) explican el sistema y se pueden ver ejemplos de los componentes y del funcionamiento del framework.
